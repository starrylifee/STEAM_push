# 📐 STEAM 도형 밀기 나라 (STEAM Math Push World) 🎮

초등학교 4학년 학생들이 직접 기획하고 디자인한 6가지 독창적인 수학 게임을 하나의 아름다운 단일 페이지 웹 애플리케이션(SPA)으로 조립한 프리미엄 교육용 플랫폼입니다. 

초등 4학년 수학 교육과정의 **"도형의 밀기(평행이동/Translation)"** 개념을 완벽하게 다루며, 비속어를 정제하고 치트성 문자열 힌트를 제거하여 실제 격자 칸수 세기 및 수학적 변위 벡터(dx, dy) 계산을 하도록 설계되었습니다.

---

## 🤖 AI 수학 마법사 로봇: 오즈 (OZ)

본 프로젝트는 수학 나라의 친근한 길잡이인 마법사 로봇 **오즈(OZ)** 마스코트와 함께합니다. 오즈는 홈 대시보드에서 학생들을 환영하며 도형 밀기 학습을 격려합니다.

---

## 🎮 6가지 미니게임 소개

### 1. 계단을 쌓아라 (🪜 기획: 서구까)
- **수학 원리**: 낙하하는 블록을 좌우로 평행이동(밀기)하여 올바른 X좌표에 맞게 쌓아올려 캐릭터의 등반 계단을 완성합니다.
- **특징**: 네모, 정육각형, 리본, 세포, 하트 등 5가지 고유 블록 텍스처 렌더링.

### 2. 글씨 밀기 게임 (✏️ 기획: 김치찌개)
- **수학 원리**: 화면에 무작위로 흩어진 자모음 조각 타일들을 상하좌우 드래그로 밀어서 단어 완성 틀에 끼웁니다.
- **특징**: 드래그 앤 드롭 및 스마트 격자 스냅 시스템 연동.

### 3. 도형을 밀어라 (🧭 기획: 고송까)
- **수학 원리**: 지시문(예: "왼쪽으로 3칸, 아래로 4칸")에 맞춰 2차원 격자 상의 도형 캐릭터를 조작하여 목표지로 평행이동시킵니다.
- **특징**: 목표지 힌트가 가려져 있어 수학적으로 계산해야 하며, 오답 시 목표 지점까지의 정밀 차이(dx, dy) 피드백이 제공됩니다. (15단계 구성)

### 4. 물 컵 밀기 게임 (🍹 기획: 도도새, 백설기, 복숭아7호)
- **수학 원리**: 중앙에 위치한 물컵을 4방향 대각선 벡터를 따라 밀어 주스 추출기에 정렬시킵니다.
- **특징**: 주스가 가득 차오르는 동적 주스 충전 버블 효과.

### 5. 사람을 미세요 (🏃 기획: 과일주스)
- **수학 원리**: 다가오는 장벽 실루엣 구멍에 캐릭터 포즈를 맞춘 뒤, 바닥 눈금자(Ruler Scale: -4, -2, 0, +2, +4)와 장벽 위치를 직접 세어 가로축(X축)으로 정밀 정렬합니다.
- **특징**: 10가지 개성 넘치는 SVG 자세 엔진 및 장벽 낙하 타이머 스릴.

### 6. 인형가게 (🧸 기획: 진라면)
- **수학 원리**: 인형 파츠를 점선 슬롯 테두리와의 거리를 세어 평행이동하여 복원하고, 바느질 노드 간의 1차 함수적 대각선 슬로프(↘, ↙) 방향을 인식해 봉합합니다.
- **특징**: 조립 및 지그재그 리듬 바느질 단계 결합, 엄격한 AI TV 머리 로봇의 점수 평가 채점.

## 🔊 Web Audio API 신디사이저 효과음
프로젝트는 외부 미디어나 음원 파일 로드 없이, 오로지 브라우저의 **Web Audio API**를 통해 100% 코드로 귀여운 레트로 8-비트 신디사이저 사운드를 즉석에서 만들어 냅니다.
- **Slide Whoosh (삼각파 변조)**: 이동 시 부드러운 바람 소리.
- **Success Chime (청아한 아르페지오)**: 성공 시 맑은 7화음 멜로디.
- **Failure Buzzer (톱니파)**: 실패 시의 저음 부저.
- **Sewing Stitch (노이즈 필터)**: 실이 통과할 때의 사각거림.
- **Juice Bubbling**: 주스가 컵에 차는 거품 소리.

## 💻 실행 및 설치 방법

이 웹 애플리케이션은 종속성이나 외부 프레임워크가 없는 순수 **Vanilla HTML5, CSS3, JavaScript**로 작성되어 서버 없이도 로컬에서 작동합니다.

1. 본 레포지토리를 클론합니다.
```bash
git clone https://github.com/starrylifee/STEAM_push.git
```
2. `index.html` 파일을 크롬, 엣지, 사파리 등 현대적인 브라우저로 엽니다.
3. (선택사항) 로컬 웹서버를 구동하여 서빙할 수도 있습니다.
```bash
python -m http.server 8080
```
이후 `http://localhost:8080`에 접속하여 플레이하세요.
